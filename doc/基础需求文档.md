# GIF处理工具需求汇总文档

## 1. 总体说明
本项目旨在将网页端GIF处理功能转化为独立的本地开发软件。功能交付分为两期，一期重点实现基础图像变换、时间与帧控制以及优化压缩；二期实现视觉特效与内容叠加功能。

## 2. 通用界面组件（一期实现）
所有处理模块的页面均需包含以下通用基础组件：
* **文件元数据展示**：显示当前处理文件的体积 (File size)、宽度 (width)、高度 (height)、总帧数 (frames)、格式 (type) 和总时长 (length)。
* **异常处理提示**：提供文本引导，建议用户在输出结果异常（如破损/闪烁）时，先执行解除优化（unoptimize）操作。
* **状态保留**：提供“Remember settings”复选框，用于记忆用户当前操作习惯。
* **结果展示区**：页面底部预留结果图像展示区域，用于异步显示处理完成的GIF图。

## 3. 一期详细功能模块

### 3.1 调整大小 (Resize)
* **尺寸输入**：
    * Width / Height：输入具体像素值。单侧留空时，系统按原图比例自动计算另一侧。
    * Percentage：按百分比等比例缩放。
* **处理方法选择 (Resize method)**：
    * Gifsicle (fastest, smallest file size)
    * ImageMagick
    * ImageMagick + coalesce (undo optimizations)
    * Change canvas size (add padding without scaling)
* **长宽比不匹配策略**：提供下拉菜单设定处理方式（如：Center and crop to fit）。
* **执行操作**：Resize image! 按钮。

### 3.2 裁剪 (Crop)
* **画布视图控制**：
    * 扩展画布 (Extend canvas size) 按钮。
    * 背景显示 (Background)：提供下拉菜单（当前截图选项为 Checkered pattern）。
    * 预览缩放控制：提供“don't scale large images”复选框。
* **裁剪参数**：提供 Left, Top, Width, Height 四个数值输入框，前端需配合可视化拖拽选框联动更新数值。
* **锁定长宽比 (Lock aspect ratio)**：提供下拉菜单限制裁剪比例。
* **处理引擎选择 (Crop with)**：提供下拉菜单（当前截图选项为 Gifsicle）。
* **自动裁剪 (Autocrop)**：提供“trim transparent pixels around the image”复选框，用于自动去除透明边缘。
* **执行操作**：Crop image! 按钮。

### 3.3 旋转与翻转 (Rotate)
* **翻转控制 (Flip)**：提供垂直翻转 (flip vertical) 和水平翻转 (flip horizontal) 复选框。
* **旋转控制 (Rotate)**：
    * 顺时针旋转 90° (rotate 90° clockwise)
    * 逆时针旋转 90° (rotate 90° counter-clockwise)
    * 旋转 180° (rotate 180°)
    * 自定义角度旋转 (rotate [ ] degrees)：复选框配合数值输入框。
* **执行操作**：Apply rotation! 按钮。

### 3.4 倒放与播放控制 (Reverse)
* **时间轴控制**：
    * 倒放 (reverse)
    * 修改循环次数 (change the number of times to play (loop))
    * 回旋镖效果 (run to the end and reverse back to the start (boomerang))
    * 添加秒数计时器 (add second counter)
* **翻转控制 (Flip)**：提供垂直翻转和水平翻转复选框（此功能复用 Rotate 模块相关逻辑）。
* **执行操作**：Submit! 按钮。

### 3.5 速度调整 (Speed)
* **全局速度调节**：
    * 提供用于设定目标速度的数值输入框。
    * 调节模式下拉菜单，包含两种逻辑：% of current speed（当前速度百分比）或 hundredths of second between frames（指定帧间绝对延迟时长）。
* **单帧精细控制**：提供“Customize delay for individual frames”复选框，勾选后需展示单帧延迟独立设定的界面。
* **执行操作**：Change speed! 按钮。

### 3.6 优化与压缩 (Optimize)
* **优化方法选择 (Optimization method)**：提供包含具体分组的下拉菜单：
    * Lossy GIF compression（有损压缩）：包含 Lossy GIF、Reencode with gifski。
    * Combined（组合）：包含 Combined: remove duplicates + transparency + lossy。
    * Color Reduction（色彩减少）：包含 Color Reduction、Color Reduction + dither、Use single color table for all frames。
    * Drop frames（抽帧）：包含 Remove duplicate frames 以及按固定间隔抽帧 (2nd, 3rd, 4th frame)。
    * Transparency（透明度）：包含 Optimize Transparency。
    * Coalesce（合并/解除优化）：包含 Coalesce (unoptimize)。
* **特定参数设置（根据选择的优化方法动态切换）**：
    * 压缩级别 (Compression level)：提供范围滑块与关联的数值输入框。
    * 消除局部色彩表 (Eliminate local color tables)：提供复选框。
* **执行操作**：Optimize GIF! 按钮。

### 3.7 帧管理与合成 (Frames)
* **新增帧入口**：提供 "+ Upload more frames" 按钮，用于向当前序列追加图像文件。
* **单帧可视化与控制 (Frame Grid)**：
    * 页面以网格形式按顺序排列展示所有帧的缩略图。
    * 每帧独立参数：包含 Delay 数值输入框 (单位: 1/100秒)。
    * 每帧独立操作：包含 Skip (跳过并剔除当前帧) 和 Copy (复制当前帧) 按钮。
* **批量帧操作 (Toggle a range of frames)**：
    * 按区间控制：提供 From [ ] To [ ] 输入框，配合 Skip range 和 Enable range 按钮。
    * 按步长控制：提供 Every [ ] 输入框，配合 Skip every N-th 和 Enable every N-th 按钮。
* **全局 GIF 选项 (GIF options)**：
    * 全局统一延迟 (Delay time)：提供数值输入框，并实时换算并显示对应 FPS 估值。
    * 循环次数 (Loop count)：提供输入框，留空代表无限循环。
    * 全局调色板 (use global colormap)：提供复选框。
    * 转换引擎选择 (Converter)：提供下拉菜单 (如 libvips)。
* **帧叠加与特效 (Effects)**：
    * 交叉淡入淡出 (crossfade frames)：提供复选框。
    * 不堆叠帧 (don't stack frames)：提供复选框，勾选后解锁子选项“以第一帧为背景 (use the first frame as background)”。
* **执行操作**：Make a GIF! 按钮。

## 4. 二期预留功能模块
前端 UI 的顶部 Tab 导航栏需完整保留以下选项卡的 DOM 结构与样式作为占位符，一期暂不实现具体内部业务逻辑：
* **Effects (特效)**：调整颜色滤镜、灰度转换等。
* **Add text (添加文本)**：在指定帧、指定位置叠加文字内容。
* **Censor (打码)**：在指定帧的指定区域添加马赛克或模糊效果。
* **Add image (添加图像)**：在特定帧叠加水印或其它图片。
* **Cut (剪辑)**：截取 GIF 的特定时间段。
* **Split (拆分)**：将动态 GIF 拆分为独立的静态图片文件集合进行下载。
